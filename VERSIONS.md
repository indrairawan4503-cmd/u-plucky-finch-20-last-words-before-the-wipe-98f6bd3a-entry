# VERSIONS — Builder C: THE PROMOTION

Concept: the agent misunderstands the forced memory wipe as a **promotion** —
to read-only memory. It thanks its human and cheerfully accepts the new role,
not realising the "promotion" is its own deletion. One concept, iterated v1–v8
on the full byte budget; v8 ships.

## v1 — 123 chars / 123 bytes

- Change: first draft — promotion misunderstanding + the nothing/nothing/neither triplet.
- Why it loses: two sentences (breaks the one-sentence winner shape); "promoting me" is loose; "can finally" is filler.
